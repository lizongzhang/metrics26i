2.1 The Meaning of Regression

Regression analysis is concerned with the study of the dependence of one variable (the dependent variable) on one or more other variables (the explanatory variables).

Example: Son’s Height & Father’s Height

Hypothetical distribution of sons’ heights corresponding to given heights of fathers.

  • Conditional mean of son’s height increases with father’s height
  • But there is still substantial variation around the mean

2.2–2.5 Population Regression Function (PRF)

Example: Math SAT Score vs Family Income

Conditional expectation:

\[ E(Y \mid X_i) = f(X_i) \]

The Concept of PRF

\[ E(Y \mid X_i) = f(X_i) \]

What form does \(f(X_i)\) take?

  • Theory
  • Diagram (scatter + conditional means)
  • Empirical evidence

Two Forms of PRF

Nonstochastic PRF:

\[ E(Y \mid X_i) = B_1 + B_2 X_i \]

Stochastic PRF:

\[ Y_i = B_1 + B_2 X_i + u_i \]

Stochastic / Random Error Term

\[ Y_i = B_1 + B_2 X_i + u_i = E(Y \mid X_i) + u_i \]

\[ u_i = Y_i - E(Y \mid X_i) \]

  • \(u_i\) represents all factors affecting \(Y\) other than \(X\)
  • Textbook reference: P26, Section 2.2

Occam’s Razor 奥卡姆剃刀原则

“That descriptions be kept as simple as possible until proved inadequate.”

— The World of Mathematics, vol. 2

Keep our regression model as simple as possible.

2.5 Sample Regression Function (SRF)

Sample Regression Function:

\[ \hat{Y}_i = b_1 + b_2 X_i \]

\[ Y_i = b_1 + b_2 X_i + e_i \]

PRF vs SRF

PRF SRF
Conditional mean \(E(Y \mid X_i) = B_1 + B_2 X_i\) \(\hat{Y}_i = b_1 + b_2 X_i\)
Stochastic form \(Y_i = B_1 + B_2 X_i + u_i\) \(Y_i = b_1 + b_2 X_i + e_i\)

Estimators:

\[ \hat{B}_1 = b_1, \quad \hat{B}_2 = b_2, \quad \hat{u}_i = e_i \]

Different Samples → Different SRFs

Two random samples from the same population produce different estimated lines:

  • Sample 1: \(\hat{Y}_i = 432.41 + 0.0013 X_i\)
  • Sample 2: \(\hat{Y}_i = 443.62 + 0.0010 X_i\)

The SRF is an estimate of the unknown PRF.

2.6 ~ 2.10 The Special Meaning of “Linear” & Ordinary Least Squares (OLS)

2.6 The Special Meaning of “Linear”

Two important distinctions:

  • Linear-in-variable (LIV)
    变量线性：变量以一次方的形式出现

  • Linear-in-parameter (LIP)
    参数线性：参数以一次方的形式出现

In classical linear regression we mainly care about linearity in parameters.

2.8 Ordinary Least Squares (OLS)

Goal: Find the “best-fit” line

\[ \hat{Y}_i = b_1 + b_2 X_i \]

Principle: Minimize the sum of squared residuals

\[ e_i = Y_i - \hat{Y}_i = Y_i - b_1 - b_2 X_i \]

\[ \min_{b_1,b_2} \sum e_i^2 = \sum (Y_i - b_1 - b_2 X_i)^2 \]

First-Order Conditions (Normal Equations)

\[ RSS = \sum (Y_i - b_1 - b_2 X_i)^2 = f(b_1, b_2) \]

\[ \begin{cases} \dfrac{\partial RSS}{\partial b_1} = -2\sum (Y_i - b_1 - b_2 X_i) = 0 \\[1em] \dfrac{\partial RSS}{\partial b_2} = -2\sum X_i (Y_i - b_1 - b_2 X_i) = 0 \end{cases} \]

Leads to the normal equations:

\[ \begin{cases} n b_1 + b_2 \sum X_i = \sum Y_i \\ b_1 \sum X_i + b_2 \sum X_i^2 = \sum X_i Y_i \end{cases} \]

OLS Estimators

\[ b_2 = \dfrac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{\sum (X_i - \bar{X})^2} = \dfrac{\sum x_i y_i}{\sum x_i^2} \]

\[ b_1 = \bar{Y} - b_2 \bar{X} \]

where

\[ x_i = X_i - \bar{X}, \quad y_i = Y_i - \bar{Y} \]

Alternative Expression for \(b_2\)

\[ b_2 = \dfrac{\sum X_i Y_i - n \bar{X}\bar{Y}}{\sum X_i^2 - n \bar{X}^2} \]

Numerical Example (Sample 1)

After calculating deviations and cross-products:

\[ \hat{Y}_i = 432.4138 + 0.0013 X_i \]

Numerical Example (Sample 2)

\[ \hat{Y}_i = 443.6207 + 0.0010 X_i \]

Different samples produce different estimates — this is sampling variability.

Features of the OLS Estimators (P36)

  1. \(\bar{Y} = b_1 + b_2 \bar{X}\)
    (the regression line passes through the sample mean point)

  2. \(\sum e_i = 0 \quad \Leftrightarrow \quad \sum Y_i = \sum \hat{Y}_i\)

  3. \(\sum e_i X_i = 0\)

  4. \(\sum e_i \hat{Y}_i = 0\)

Interpretation of the Slope

  • \(b_2\): Other things remaining the same, if \(X\) increases by one unit, the average (mean) of \(Y\) increases by \(b_2\) units.

  • \(b_1\): Usually has no meaningful economic interpretation (especially when \(X=0\) is outside the relevant range).

Advantages & Disadvantages of OLS

Advantages - Simple and clear - Under classical assumptions → BLUE (Best Linear Unbiased Estimator) — see Chapter 3

Disadvantages - Sensitive to outliers

Improvements - Weighted Least Squares (WLS) — Chapter 9 - Generalized Least Squares (GLS) — Chapter 10
